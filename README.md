# 🇮🇷 بخش فارسی (Persian)

## 📖 درباره برنامه

**UFTP Server (Universal FTP Server)** یک اپلیکیشن بومی و مدرن اندروید است که گوشی یا تبلت شما را به یک سرور انتقال فایل پرسرعت و امن تبدیل می‌کند. این برنامه با استفاده از **Google AI Studio** و با بهره‌گیری از پشته نرم‌افزاری مدرن اندروید (**Kotlin** و **Jetpack Compose**) توسعه داده شده است.

این نرم‌افزار به شما اجازه می‌دهد بدون نیاز به کابل‌های خاص، بدون اینترنت و بدون نیاز به نصب هیچ نرم‌افزار جانبی روی کامپیوتر (تنها با مرورگر فایل خود سیستم‌عامل مثل File Explorer ویندوز یا کلاینت‌هایی مانند FileZilla و WinSCP)، فایل‌های گوشی خود را با حداکثر سرعت مدیریت، کپی، دانلود و جابه‌جا کنید.

---

## ✨ امکانات و قابلیت‌های کلیدی

### ۱. پشتیبانی از دو پروتکل قدرتمند
* ⚡ **پروتکل استاندارد FTP (پورت پیش‌فرض ۲۱۲۱):** سازگار با تمام مرورگرها، تلویزیون‌های هوشمند و ویندوز File Explorer با پشتیبانی از دستورات RFC 959 (حالت‌های Passive و Active).
* 🔒 **پروتکل امن و رمزنگاری‌شده SFTP بر بستر SSH (پورت پیش‌فرض ۲۲۲۲):** پیاده‌سازی شده با کتابخانه قدرتمند **Apache SSHD**، تولید کلید RSA در حافظه و رمزنگاری سرتاسری مناسب برای کلاینت‌های حرفه‌ای (FileZilla، Termius و WinSCP).

### ۲. اتصال چهارگانه (بدون نیاز به اینترنت و مودم)
* 🔌 **اتصال فوق سریع با کابل (USB Tethering):** بالاترین سرعت ممکن برای انتقال فایل‌های حجیم و فیلم‌ها؛ کاملاً مستقل، آفلاین و بدون مصرف اینترنت.
* 📶 **هات‌اسپات گوشی (Mobile Hotspot):** ساخت شبکه بی‌سیم محلی مستقل با خود گوشی، مناسب زمان‌هایی که مودم یا روتر در دسترس نیست.
* 🌐 **شبکه وای‌فای مشترک (Wi-Fi):** اشتراک‌گذاری فایل‌ها بین تمام دستگاه‌های متصل به مودم خانگی یا اداری.
* 🔵 **شبکه بلوتوث (Bluetooth PAN):** دسترسی به فایل‌ها از طریق شبکه بلوتوث با مصرف بسیار ناچیز باتری.

### ۳. مدیریت پیشرفته حافظه و فایل‌ها
* 📱 **پشتیبانی از حافظه داخلی و کارت حافظه (SD Card):** دسترسی مستقیم به حافظه گوشی یا اسلات حافظه جانبی.
* 📂 **انتخاب پوشه سفارشی با Android SAF:** امکان به اشتراک گذاشتن فقط یک پوشه خاص به جای کل حافظه با سیستم رسمی انتخاب‌گر اندروید (Storage Access Framework).
* 🛡 **قابلیت فقط‌خواندنی (Read-Only Mode):** جلوگیری از حذف یا ویرایش ناخواسته فایل‌های حساس توسط کلاینت‌ها.

### ۴. امنیت و پایداری در پس‌زمینه
* 👤 **ورود ناشناس یا با رمز عبور:** قابلیت ورود مهمان (Anonymous) یا تعریف نام‌کاربری و رمز عبور اختصاصی.
* 🛡 **فیلتر امنیتی شبکه:** مسدودسازی خودکار دسترسی از طریق دیتای سیم‌کارت و VPN برای جلوگیری از مصرف اینترنت و نفوذ خارجی.
* 🔋 **سرویس پس‌زمینه پایدار (Foreground Service):** فعال ماندن انتقال فایل‌ها حتی در صورت قفل شدن صفحه گوشی به کمک قفل پردازنده (WakeLock) و قفل وای‌فای (WifiLock).
* 📜 **لاگ لحظه‌ای (Live Activity Logs):** نمایش زنده تمام رویدادها، ورود و خروج کلاینت‌ها و ترافیک فایل‌ها با قابلیت کپی.
* 💡 **راهنمای گام‌به‌گام اتصال:** شامل آموزش اتصال تصویری و قدم‌به‌قدم برای ویندوز، مک، لینوکس و نرم‌افزار FileZilla.

# 🇬🇧 English Section

## 📖 About The App

**UFTP Server (Universal FTP Server)** is a modern, native Android application that turns your device into a robust, high-speed file transfer server. Built using **Google AI Studio** with modern Android development standards (**Kotlin** and **Jetpack Compose**), it delivers seamless local file transfers without reliance on cloud services, external internet access, or proprietary PC software.

Access your device's internal storage and SD card directly from Windows File Explorer, macOS Finder, Linux, or dedicated clients like FileZilla and WinSCP.

---

## ✨ Features

* 🚀 **Dual Protocols:**
  * **Standard FTP** (Port `2121`): Lightweight RFC 959 compliant server with full UTF-8, MLSD, and PASV support.
  * **Encrypted SFTP / SSH** (Port `2222`): Powered by **Apache SSHD** with in-memory 2048-bit RSA keypair generation for high-security transfers.
* 🌐 **4 Offline Network Modes:**
  * **USB Tethering:** Maximum cable transfer speed without consuming mobile data or requiring a local router.
  * **Mobile Hotspot (Wi-Fi AP):** Create an instant ad-hoc network anywhere directly from your phone.
  * **Local Wi-Fi:** Seamlessly share files across home/office network routers.
  * **Bluetooth Network (PAN):** Low-power network access via Bluetooth tethering.
* 📁 **Granular Storage Management:**
  * Auto-detects Internal Storage and removable SD Cards / USB OTG drives.
  * Integrated with Android's **Storage Access Framework (SAF)** to isolate sharing to specific custom folders.
  * **Read-Only Mode** toggle to prevent accidental modifications or file deletions.
* 🔒 **Security & Authentication:**
  * Toggle between Anonymous Guest login or custom Username / Password credentials.
  * Strict interface filtering to exclude cellular mobile data (LTE/5G) and VPN interfaces.
* 🔋 **Uninterrupted Background Operations:**
  * Dedicated Android Foreground Service with status bar notifications.
  * Configurable **CPU Partial WakeLock** and **Wi-Fi High-Performance Lock** to ensure multi-gigabyte transfers complete without dropping.
* 📊 **Real-Time Diagnostics:**
  * Live connection counter and session uptime timer.
  * Built-in Activity Logs sheet with one-click copy and clear options.
  * Comprehensive interactive connection guides for Windows, macOS, Linux, and FTP clients.
